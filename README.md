# Test Dev Full-Stack

## Front-End

```bash
cd frontend

# Installer les dépendances
npm install

# Démarrer
npm run dev
```

Accessible sur : [http://localhost:3000](http://localhost:3000)

## Back-End

```bash
cd backend

# Installer les dépendances
npm install

# Démarrer
npm run dev
```

Accessible sur : [http://localhost:5000](http://localhost:5000)
